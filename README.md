# Egyptian Real Estate Market Analysis 

An end-to-end Exploratory Data Analysis (EDA) project focusing on the Egyptian real estate market. This project aims to clean, analyze, and visualize real estate data to extract valuable insights regarding property types, pricing trends, and size relationships.

## Key Highlights & Insights:
- **Property Distribution:** Analyzed the distribution of various property types (e.g., Apartments, Chalets, Villas) and their market shares.
- **Price Analysis:** Used logarithmic scales and statistical metrics (Median/Mean) to handle right-skewed pricing data and identify high-value properties.
- **Size vs. Price Correlation:** Explored the relationship between property sizes and prices across different housing segments.

## Tech Stack & Libraries:
- **Python** 
- **Pandas & NumPy** (Data Cleaning & Manipulation)
- **Matplotlib & Seaborn** (Data Visualization)
- **Visual Studio Code & Jupyter Notebook**
